📊 Plotly layout() Reference Cards

Interactive Visual Representation - Practitioner's Guide

Block 1: Core Components & Structure

1

📐 Basic Layout Structure

plot_ly(data, x = ~x, y = ~y, type = "scatter") %>% layout( title = "", xaxis = list(), yaxis = list(), margin = list(), legend = list(), annotations = list() )
💡 Tip: Always start with this skeleton and build incrementally.

🎨 Title & Font Configuration

layout( title = list( text = "Main Title", font = list(family = "Arial", size = 24, color = "#2c3e50"), x = 0.5, xanchor = "center", y = 0.95 ), font = list(family = "Roboto", size = 14, color = "#34495e") )
💡 Tip: Use global font settings for consistency.

📏 Margins & Canvas Control

layout( margin = list(l = 80, r = 50, t = 100, b = 80, pad = 4), paper_bgcolor = "#ffffff", plot_bgcolor = "#f8f9fa" )
💡 Tip: Adjust margins for different output formats.

Block 2: Axes, Grids & Scales

2

📊 Axis Configuration

xaxis = list( title = "X Axis Label", titlefont = list(size = 16, color = "#7f8c8d"), tickfont = list(size = 12), showgrid = TRUE, gridcolor = "#ecf0f1", zeroline = FALSE, range = c(0, 100) )
💡 Tip: Use range limits to focus on relevant data areas.

🎯 Custom Tick Labels

tickmode = "array", tickvals = c(0, 25, 50, 75, 100), ticktext = c("Start", "Q1", "Median", "Q3", "End"), ticks = "outside", ticklen = 5
💡 Tip: Custom tick text improves readability for non-technical audiences.

📐 Range Slider Integration

layout( xaxis = list( rangeslider = list(visible = TRUE), rangeselector = list( buttons = list( list(count = 1, label = "1m", step = "month"), list(count = 6, label = "6m", step = "month") ) ) ) )
💡 Tip: Essential for time series exploration.

Block 3: Annotations, Shapes & Highlights

3

✏️ Storytelling Annotations

annotations = list( list( x = 2.5, y = 85, text = "Key Insight", showarrow = TRUE, arrowhead = 2, font = list(size = 14, color = "#e74c3c"), bgcolor = "rgba(255,255,255,0.9)" ) )
💡 Tip: Use annotations to guide viewers through key data points.

🔍 Region Highlighting

shapes = list( list( type = "rect", x0 = 0, x1 = 1, y0 = 70, y1 = 100, fillcolor = "#3498db", opacity = 0.1, line = list(width = 0) ) )
💡 Tip: Semi-transparent shapes draw attention without obscuring data.

📏 Reference Lines

shapes = list( list( type = "line", x0 = 5.5, x1 = 5.5, y0 = 0, y1 = 100, line = list(color = "#e74c3c", width = 2, dash = "dash") ) )
💡 Tip: Dashed lines indicate thresholds or targets.

Block 4: Performance, Themes & Export

4

⚡ Performance Optimization

layout( hovermode = "closest", hoverdistance = 50, dragmode = "zoom", uirevision = TRUE )
💡 Tip: Use uirevision to preserve user interactions on updates.

🎨 Reusable Theme Function

my_theme <- function(p) { p %>% layout( font = list(family = "Arial"), paper_bgcolor = "#ffffff", plot_bgcolor = "#f5f5f5", margin = list(l = 60, r = 30, t = 80, b = 50) ) } # Usage: plot_ly(...) %>% my_theme()
💡 Tip: Create themes for consistent corporate branding.

📱 Responsive Sizing

layout( autosize = TRUE, height = NULL, # Adaptive margin = list(l = 40, r = 20, t = 40, b = 30) ) # Dynamic sizing height = max(400, nrow(data) * 30)
💡 Tip: Dynamic height calculation for variable data sizes.

🖨️ Presentation-Ready Layout

# For presentations: layout( margin = list(l = 80, r = 80, t = 120, b = 100), font = list(size = 16), title = list(font = list(size = 28)), xaxis = list(titlefont = list(size = 18)), yaxis = list(titlefont = list(size = 18)) )
💡 Tip: Larger fonts and margins for slide presentations.
