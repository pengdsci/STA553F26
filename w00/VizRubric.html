📊 Data Visualization Grading Rubrics

📋 1. Required Components axis/title/legend/source
Excellent (4) : All components: clear title, axis labels+units, legend (if needed), data source citation, annotations. No omissions.
Satisfactory (3) : Missing one minor component (e.g., data source or units on one axis).
Needs Improvement (2) : Missing two components (e.g., no legend and unclear axis labels).
Unsatisfactory (1) : Missing three or more components, figure uninterpretable without external text.
📌 Checklist: title, units, source, legend, annotations
📈 2. Chart Type Appropriateness match data-story
Excellent : Perfectly matches data type & question (time series → line; comparisons → bar; parts of whole → bar instead of pie >3 categories).
Satisfactory : Appropriate but slightly better alternative exists (e.g., pie chart for 4 categories).
Needs Improvement : Suboptimal chart type (line chart for categorical X) but still readable.
Unsatisfactory : Completely wrong chart type (pie chart for time series) → misleading.
🎯 Best: bars for ranking, lines for trends, avoid pies when >3 slices.
🎯 3. Clarity & Accuracy truthful encoding
Excellent : All encodings accurate. Bar charts start at zero (or clearly annotated). No distortion.
Satisfactory : Minor scaling issue (truncated axis but labeled “zero not shown”), still truthful.
Needs Improvement : Axis truncation without warning or hard-to-read gridlines affecting interpretation.
Unsatisfactory : Deliberate or accidental distortion (bar charts not starting at zero, misleading dual axes).
📏 Tufte integrity: start bars at zero, annotate breaks.
🎨 4. Color & Contrast accessible + consistent
Excellent : Colorblind-friendly, high contrast, consistent mapping, no unnecessary colors.
Satisfactory : Colors distinguishable but mild contrast issues, or one redundant color.
Needs Improvement : Overly bright/low contrast; color without purpose (rainbow for single variable).
Unsatisfactory : Relies solely on problematic colors (red-green confusion) or grayscale indistinguishable.
🌈 Use viridis, Okabe-Ito; check grayscale & WCAG contrast.
🔤 5. Typography & Labels legible + clean
Excellent : Sans-serif, all labels horizontal/justifiable rotation, ≥10pt, no clutter.
Satisfactory : Minor issues (some labels rotated 90°, slightly small but readable).
Needs Improvement : Overlapping labels, tiny text (<8pt), abbreviations unexplained.
Unsatisfactory : Illegible text, missing axis labels, unreadable title.
✍️ Guidelines: title 14-16pt, axis 10-12pt, legend 9-10pt.
✨ 6. Data-Ink Ratio minimalism
Excellent : Clean: no extraneous gridlines, borders, 3D, gradients, or backgrounds. Data stands out.
Satisfactory : Minor excess ink (light default gridlines but not distracting).
Needs Improvement : Heavy gridlines, unnecessary 3D, background images, excessive decorations.
Unsatisfactory : “Chartjunk” dominates; data is hard to find.
🧹 Remove 3D, redundant borders, heavy backgrounds.
🔄 7. Consistency & Alignment coherent design
Excellent : Repeated elements consistent across panels/figures. Strong alignment.
Satisfactory : Mostly consistent, one small slip (legend order differs from bars).
Needs Improvement : Noticeable inconsistencies (same variable different colors in multi‑plot).
Unsatisfactory : Random or chaotic design decisions.
📐 Unified color palette, aligned axes, consistent symbols.
♿ 8. Accessibility & Annotation inclusive + insight
Excellent : Interpretable in grayscale, includes alt‑text/description, key patterns annotated (e.g., “peak in July”).
Satisfactory : Accessible but missing 1–2 annotations or alt‑text.
Needs Improvement : No annotations for key insights; grayscale causes ambiguity.
Unsatisfactory : Only readable with perfect color vision & extensive prior explanation.
📢 Add figure captions, pattern callouts, alt text.
