📊 Creating Plotly layout() in R: Comprehensive Reference

Customize axes, legends, annotations, shapes & interactive controls with layout()
🏷️ Title & Fonts layout()

Set main title and global font:

layout( title = list( text = "Plot Title", font = list( family = "Arial", size = 24, color = "black"), x = 0.5, y = 0.95, xanchor = "center", yanchor = "top" ), font = list( family = "Arial, sans-serif", size = 14, color = "#333333" ) )

Title position formula (paper coordinates):

$$x \in [0,1],\quad y \in [0,1]$$ $$\text{Center: } x=0.5,\; \text{yanchor}=\text{"top"}$$
📏 Axes Customization xaxis / yaxis

Axis type, range, ticks:

layout( xaxis = list( title = "X Axis Label", range = c(0, 100), type = "linear", tickmode = "linear", tick0 = 0, dtick = 20, tickangle = -45, showgrid = TRUE, gridcolor = "#e5e5e5", zeroline = TRUE, showline = TRUE, mirror = TRUE, side = "bottom" ), yaxis = list(...) )

Axis types: "linear" | "log" | "date" | "category"

$$\text{tick positions} = \text{tick0} + k \times \text{dtick},\; k \in \mathbb{Z}$$
🔄 Secondary Axes xaxis2 / yaxis2

Overlay secondary axes:

layout( xaxis2 = list( overlaying = "x", side = "top", title = "Secondary X Axis" ), yaxis2 = list( overlaying = "y", side = "right", title = "Secondary Y Axis" ) )

Key R functions:

  • plot_ly() – add traces with yaxis = "y2"
  • add_trace() – assign to secondary axis
  • subplot() – multiple plots with shared axes
$$\text{yaxis2 range mapped independently: } [y_{\min2},\; y_{\max2}]$$
📖 Legend legend

Position, orientation, interaction:

layout( showlegend = TRUE, legend = list( title = list(text = "Legend"), x = 1.02, y = 1, xanchor = "left", yanchor = "top", orientation = "v", traceorder = "normal", bgcolor = "rgba(255,255,255,0.8)", bordercolor = "black", borderwidth = 1, itemclick = "toggle", itemdoubleclick = "toggleothers" ) )
$$\text{Legend position: } (x,y) \text{ in paper coords, } x>1 \text{ = outside}$$
📐 Margins & Size margin / width / height

Control plot dimensions:

layout( margin = list( l = 80, r = 80, t = 100, b = 80, pad = 4, autoexpand = TRUE ), width = 800, height = 600, autosize = TRUE )
$$\text{Total width} = \text{margin.l} + \text{plot area} + \text{margin.r}$$ $$\text{All units in pixels (px)}$$
🖱️ Hover Labels hoverlabel / hovermode

Customize tooltip appearance:

layout( hovermode = "closest", hoverlabel = list( font = list( size = 13, color = "white", family = "Arial"), bgcolor = "rgba(0,0,0,0.8)", bordercolor = "white", namelength = -1, align = "left" ), hoverdistance = 20, spikedistance = 20, clickmode = "event+select" )

Hover modes: "x" | "y" | "closest" | "x unified" | "y unified" | FALSE

🔷 Shapes & Lines shapes

Add reference lines, rectangles, circles:

layout( shapes = list( list(type = "line", x0 = 0, x1 = 1, xref = "paper", y0 = 50, y1 = 50, yref = "y", line = list(color = "red", width = 2, dash = "dash")), list(type = "rect", x0 = 2, x1 = 8, y0 = 10, y1 = 50, fillcolor = "rgba(0,100,255,0.1)", line = list(width = 0)) ) )

Reference types: "x" | "y" | "paper" | "x domain"

✏️ Annotations annotations

Add text labels with arrows:

layout( annotations = list( list( text = "Important Point", x = 5, y = 50, xref = "x", yref = "y", showarrow = TRUE, arrowhead = 2, arrowsize = 1.5, arrowwidth = 2, arrowcolor = "red", ax = 20, ay = -30, font = list( size = 12, color = "red"), bgcolor = "rgba(255,255,255,0.8)", bordercolor = "red", borderwidth = 1, borderpad = 4, xanchor = "center", yanchor = "bottom" ) ) )
$$\text{Arrow offset: } (ax, ay) \text{ in pixels from point } (x,y)$$
🖼️ Images & Logos images

Embed background/foreground images:

layout( images = list( list( source = "https://example.com/logo.png", xref = "paper", yref = "paper", x = 1.05, y = 1.02, sizex = 0.15, sizey = 0.15, xanchor = "right", yanchor = "top", opacity = 0.8, layer = "above" ) ) )
$$\text{Size in paper coords: sizex, sizey } \in [0,1]$$ $$\text{Layer: "above" | "below"}$$
🎨 Colors & Themes template / colorway

Built-in templates and color scales:

layout( plot_bgcolor = "#f8f9fa", paper_bgcolor = "white", colorway = c("#636EFA", "#EF553B", "#00CC96", "#AB63FA"), coloraxis = list( colorscale = "Viridis", colorbar = list( title = "Scale", len = 0.75, thickness = 20) ), template = "plotly_dark" )

Templates: "ggplot2" | "plotly_white" | "seaborn" | "plotly_dark" | "presentation"

🎚️ Sliders & Selectors rangeslider / rangeselector

Range slider and time selector:

layout( xaxis = list( rangeslider = list( visible = TRUE, thickness = 0.05, bgcolor = "#f0f0f0", borderwidth = 1 ), rangeselector = list( buttons = list( list(count = 1, label = "1m", step = "month", stepmode = "backward"), list(count = 6, label = "6m", step = "month", stepmode = "backward"), list(step = "all", label = "All") ) ) ) )

Key R function: plot_ly() %>% layout() with time-series data

🔘 Dropdowns & Buttons updatemenus

Interactive controls for relayout:

layout( updatemenus = list( list( type = "buttons", direction = "right", x = 1.05, y = 1.1, xanchor = "left", yanchor = "top", buttons = list( list( label = "Log Scale", method = "relayout", args = list( list(yaxis = list(type = "log"))) ), list( label = "Linear Scale", method = "relayout", args = list( list(yaxis = list(type = "linear"))) ) ) ) ) )
$$\text{Method: "relayout" | "update" | "animate"}$$ $$\text{Type: "buttons" | "dropdown"}$$
🧩 Subplots Grid subplot()

Combine multiple plots:

# Key R function: subplot() subplot(p1, p2, p3, p4, nrows = 2, shareX = TRUE, shareY = TRUE, titleX = TRUE, titleY = TRUE, heights = c(0.6, 0.4), widths = c(0.5, 0.5) ) %>% layout( annotations = list( list(x = 0.2, y = 1.02, text = "Panel A", xref = "paper", yref = "paper", showarrow = FALSE) ) )
$$\text{Total subplots} = n_{\text{rows}} \times n_{\text{cols}}$$ $$\sum \text{heights} = 1,\; \sum \text{widths} = 1$$
📝 Publication-Ready Theme Clean layout template

Minimal, clean layout for publications:

layout( font = list( family = "serif", size = 12), plot_bgcolor = "white", paper_bgcolor = "white", xaxis = list( showgrid = TRUE, gridcolor = "lightgray", showline = TRUE, linecolor = "black", mirror = TRUE ), yaxis = list( showgrid = TRUE, gridcolor = "lightgray", showline = TRUE, linecolor = "black", mirror = TRUE ), legend = list( bgcolor = "rgba(255,255,255,0)", borderwidth = 0 ) )
📌 Axis Reference Types xref / yref

Reference coordinate systems:

xref / yrefDescription
"x" / "y"Data coordinates on primary axis
"x2" / "y2"Secondary axis data coordinates
"paper"0–1 relative to entire figure
"x domain"0–1 within axis domain (subplots)
$$\text{paper: } (0,0) = \text{bottom-left},\; (1,1) = \text{top-right}$$ $$\text{domain: } (0,0) = \text{axis origin},\; (1,1) = \text{axis end}$$
🧪 Essential R Functions plotly package

Core plotly R workflow:

# Create plot plot_ly(data, x = ~x, y = ~y, type = "scatter", mode = "lines+markers") # Add traces add_trace(p, x = ~x2, y = ~y2, yaxis = "y2") # Apply layout layout(p, title = "My Plot") # Pipe syntax plot_ly(...) %>% add_trace(...) %>% layout(...) # ggplotly conversion ggplotly(ggplot_object) %>% layout(...)
  • plot_ly() – initialize plot
  • add_trace() – add data layers
  • layout() – customize everything
  • subplot() – combine plots
  • ggplotly() – convert ggplot2
  • style() – modify trace properties
  • config() – control modebar
  • animation_opts() – animation settings
