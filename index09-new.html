Assignments

As part of Project #4 (Tableau Dashboard), you'll create a few interconnected charts using Tableau Public. These charts will serve as the building blocks for your final dashboard. The goal of this assignment is to help you get comfortable with Tableau Public and its features, while giving you hands-on practice in building interactive visualizations that tell a clear story from data.

  1. The guideline for this assignment:: [Project Guidelines]
  2. Four-Step Process for Building an Effective Dashboard: Dashboard Reference Cards
  3. Data Set Selection: Pick a data set that you find interesting. Choose one that helps you shape your data story and build a meaningful dashboard for effective storytelling. See detailed instructions in the Project Guidelines
  4. Assignment Coverage
    • a. Drafting a data story
    • b. Creating a sequence of interconnected charts relecting the data story.
  5. Due Date: Sunday, 11:59 PM
