🔍 Spatial Patterns 1/12

Reveal invisible clusters. Geocoded points show relationships hidden in tables.

$$\text{Pattern} = f(\text{location density})$$
# Kernel density estimation (points) library(sf); library(ggplot2) ggplot(data = points_sf) + stat_density_2d(aes(x = st_coordinates(geometry)[,1], y = st_coordinates(geometry)[,2], fill = after_stat(level)), geom = "polygon")
📏 Proximity / Containment 2/12

Distance & polygon queries. Answers "how close" and "inside which area".

$$d(i,j) = \sqrt{ (x_i - x_j)^2 + (y_i - y_j)^2 }$$
# Distance matrix & point-in-polygon library(sf) st_distance(customers, stores) # great circle if CRS=4326 st_join(points, polygons, join = st_within)
🧲 Spatial Autocorrelation 3/12

Moran's I & LISA. "Near things are more related than distant things."

$$I = \frac{N}{W} \frac{\sum_i\sum_j w_{ij}(x_i-\bar{x})(x_j-\bar{x})}{\sum_i (x_i-\bar{x})^2}$$
library(spdep) nb <- poly2nb(polygons, queen=TRUE) lw <- nb2listw(nb, style="W") moran.test(polygons$value, lw) localmoran(polygons$value, lw)
🧠 Feature Engineering 4/12

Geocode → predictors. Distance to highway, population density, competitor count.

$$\text{Feature}_{new} = g(\text{lat},\text{lon}, \text{external layers})$$
# Extract raster value at points library(raster); library(sf) pop_density <- extract(pop_raster, points_sf) points_sf$dist_road <- st_distance(points_sf, major_roads) |> apply(1, min)
🧩 DBSCAN Clustering 5/12

Density-based spatial clustering. Finds clusters of arbitrary shape, marks noise.

$$\text{Core point if } |N_{\epsilon}(p)| \ge \text{minPts}$$
library(dbscan) cl <- dbscan(st_coordinates(points_sf), eps = 0.008, minPts = 10) points_sf$cluster <- cl$cluster
📈 Spatial Regression 6/12

Fix spatial dependence. Spatial lag or error model when OLS fails.

$$y = \rho W y + X\beta + \epsilon \quad \text{(Spatial Lag)}$$
library(spatialreg) lagsarlm(price ~ income + dist, data = df, listw = lw, method = "eigen")
🎨 Choropleth Maps 7/12

Normalize wisely. Map rates (per capita, per area), not raw totals.

$$\text{Rate} = \frac{\text{Event count}}{\text{Population}} \times 1000$$
library(tmap) tm_shape(counties) + tm_polygons(col = "crime_rate", style = "jenks", palette = "Purples")
🔥 Heatmap / Kriging 8/12

Continuous surfaces from points. IDW, Kriging for prediction.

$$\hat{z}(s_0) = \sum_{i=1}^{N} \lambda_i z(s_i)$$
library(gstat) idw.out <- idw(value ~ 1, locations = points, newdata = grid) # or fit variogram + krige
🔗 Spatial Joins 9/12

Combine attributes by location. Merge polygon data to points, or aggregate points to polygons.

$$\text{Join} = \text{Point} \bowtie_{\text{within}} \text{Polygon}$$
# Spatial join: attach census data to points library(sf) points_with_tract <- st_join( points_sf, census_tracts, join = st_within )
📍 Geocoding Quality 10/12

Match score & precision. Rooftop vs. centroid vs. street-level accuracy matters.

$$\text{Accuracy} = \frac{\text{Correct matches}}{\text{Total addresses}} \times 100\%$$
# Using tidygeocoder for batch geocoding library(tidygeocoder) result <- addresses %>% geocode(address = street, method = 'census', full_results = TRUE)
🌐 CRS & Projections 11/12

EPSG codes matter. Geographic (4326) vs. projected (UTM, Albers) for accurate measurement.

$$\text{dist} = \text{st_distance}(A, B) \quad \text{(use projected CRS)}$$
# Transform to projected CRS for meters library(sf) points_proj <- st_transform(points_sf, 32633) st_distance(points_proj[1,], points_proj[2,])
🖱️ Interactive Maps 12/12

Leaflet & tmap view mode. Pan, zoom, popups for exploration and dashboards.

$$\text{Map} = \text{basemap} + \text{markers} + \text{popups}$$
library(leaflet) leaflet(data = points_sf) %>% addTiles() %>% addCircleMarkers( popup = ~name, radius = 5, color = "#6E3061" )
