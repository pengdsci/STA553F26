📊 Histogram Distribution

Concept: Shows the distribution of a continuous measure by dividing it into bins (intervals). Each bar represents the count of records falling into that bin.

Step‑by‑Step Procedure:
  1. Create a bin for your measure: In the Data pane, right-click the measure (e.g., Sales).
  2. Select Create → Bins...
  3. In the dialog, set the bin size (Tableau suggests a default; adjust based on your data granularity). Click OK. This creates a new dimension like Sales (bin).
  4. Build the chart: Drag the newly created bin dimension to Columns.
  5. Drag the same measure (or any measure) to Rows. Tableau defaults to SUM().
  6. Right-click the pill on Rows and change the aggregation to Measure → Count (or CNT()).
  7. Adjust appearance: On the Marks card, use the Size slider and drag it fully to the right to remove gaps between bars (making it a true histogram).
💡 Pro Tip: Drag a categorical dimension to Color on the Marks card to see the distribution split by category.
Shortcut In Show Me, select "Histogram" (requires one measure) — Tableau auto-creates the bin.
📈 Density Curve Smooth distribution

Concept: A smoothed version of a histogram, showing the probability density function of a continuous variable. The area under the curve sums to 1.

Step‑by‑Step Procedure:
  1. Set up a basic histogram first (see Histogram card above) so you have a measure bin on Columns and CNT() on Rows.
  2. Change mark type to Area: On the Marks card, change the dropdown from Automatic/Bar to Area. This creates a filled density shape.
  3. For a true smooth density curve (alternative method): Drag your continuous measure directly to Columns (no bin).
  4. From the Analytics pane, drag Distribution Band into the view.
  5. In the dialog that appears, under "Computation," choose:
    • Percentiles (shows shaded regions) or
    • Probability Density (smooth curve)
  6. Adjust the shading, line colors, and band percentages in the Edit dialog as needed.
  7. Optionally, format the band to show only the outline for a clean density line.
💡 Note: There is no native "Density Curve" button in Show Me — manual setup is required for full control over the smoothing.
📊 Bar Chart Comparison

Concept: Compares values across discrete categories. Bars can be vertical (default) or horizontal. Supports grouping, stacking, and sorting.

Step‑by‑Step Procedure:
  1. Place dimensions and measures: Drag a categorical dimension (e.g., Region) to Columns.
  2. Drag a measure (e.g., Sales) to Rows. Tableau defaults to vertical bars with SUM(Sales).
  3. Swap orientation for horizontal bars: Click the Swap icon on the toolbar (or drag pills to opposite axes).
  4. Sort: Click the sort icon (ascending/descending) on the axis to order bars by value.
  5. Add color: Drag another dimension to Color on the Marks card to create stacked or grouped bars.
  6. Add labels: Drag the measure (or any measure) to Label on the Marks card to display values on bars.
  7. Adjust spacing: Use the Size slider on the Marks card to control bar width and gap between bars.
💡 Pro Tip: To create a grouped bar chart (side-by-side), ensure the dimension on Color is placed before or after the Columns dimension appropriately. Use the Analysis → Stack Marks menu to toggle stacking on/off.
Shortcut With one dimension and one measure selected, choose "Horizontal Bars" or "Stacked Bars" from Show Me.
🔵 Scatter Plot Relationship

Concept: Displays the relationship between two continuous measures. Each mark represents one record or aggregation. Ideal for identifying correlations, clusters, and outliers.

Step‑by‑Step Procedure:
  1. Place measures on axes: Drag one measure (e.g., Profit) to Columns.
  2. Drag another measure (e.g., Sales) to Rows. Tableau creates one aggregated mark if no detail dimension is used.
  3. Disaggregate or add detail: To see every individual record, go to Analysis → Aggregate Measures and uncheck it. Better approach: Drag a unique identifier dimension (e.g., Customer ID) to Detail on the Marks card so each mark represents one entity.
  4. Encode additional dimensions: Drag a categorical dimension to Color to group points by category.
  5. Drag a measure to Size to create a bubble scatter plot (varying point sizes).
  6. Add trend line: From the Analytics pane, drag Trend Line onto the chart. Choose Linear, Logarithmic, Exponential, or Polynomial in the dialog.
  7. Hover over the trend line to see R-squared and p-value. Right-click to edit or describe the trend model.
💡 Pro Tip: Use Pages shelf with a date field to animate the scatter plot over time. Add Reference Lines from the Analytics pane to mark thresholds.
Shortcut Select two measures and pick "Scatter Plot" from Show Me.
📦 Box Plot Quartiles & outliers

Concept: Also called a box-and-whisker plot. Summarizes distribution using five numbers: minimum, Q1 (25th percentile), median (Q2), Q3 (75th percentile), and maximum. Whiskers extend to 1.5 × IQR; points beyond are outliers.

Step‑by‑Step Procedure:
  1. Set up the view: Drag a continuous measure (e.g., Sales) to Rows.
  2. Drag a categorical dimension (e.g., Region) to Columns. (For a single box plot, drag the dimension to Detail instead.)
  3. Change to box plot: On the Marks card, change the mark type dropdown to Circle (this is temporary, to give Tableau a mark to work with).
  4. From the Analytics pane, drag Box Plot onto the view. Drop it onto the cell (the plot area). Tableau adds box-and-whisker marks showing median, IQR, and whiskers.
  5. Clean up: Hide the original circle marks if they still appear by removing the circle mark or using a dual-axis trick to overlay them.
  6. Format: Right-click the box plot axis or the box itself and choose Edit Reference Line to adjust whisker length, colors, fill, and outlier display.
💡 Important: Box plots work best when a dimension partitions the data into groups. Without a dimension on Columns or Detail, you get a single summary box for the entire dataset.
Formula IQR = Q3 − Q1 · Whiskers: Q1−1.5×IQR to Q3+1.5×IQR
🥧 Pie Chart Part-to-whole

Concept: Shows proportions of a whole as slices of a circle. Each slice represents a category's contribution to the total (360°). Best with fewer than 6 categories for readability.

Step‑by‑Step Procedure:
  1. On the Marks card, change the mark type dropdown from Automatic to Pie.
  2. Drag a categorical dimension (e.g., Category) to Color on the Marks card. Each slice gets a distinct color from the palette.
  3. Drag a measure (e.g., Sales) to Angle on the Marks card. Tableau calculates each slice's angle proportionally: (category value / total) × 360°.
  4. Drag the same dimension (or a label-friendly field) to Label on the Marks card.
  5. Click Label on the Marks card, then check Show mark labels. Customize to display:
    • Category name (from the dimension)
    • Value (from the measure)
    • Percent of total (right-click measure on Angle → Quick Table Calculation → Percent of Total)
  6. Sort slices: Right-click the dimension on Color and select Sort. Sort by the measure descending to order slices from largest to smallest.
  7. Explode slices: Click on a slice and drag it outward to emphasize a particular category.
💡 Pro Tips:
• Use Quick Table Calculation → Percent of Total on the Angle measure to display percentage labels.
• Avoid pie charts for many categories or precise comparisons — use bar charts instead.
• Combine with Filter to show top N categories and group the rest as "Other."
Shortcut Select 1 dimension + 1 measure, then choose "Pie Chart" from Show Me.
🍩 Donut Chart Ring / hole in center

Concept: A variation of the pie chart with a hollow center. The donut shape improves readability by focusing attention on arc lengths rather than slice angles. The center hole can display a summary metric (e.g., total sales, grand total count).

Step‑by‑Step Procedure:
  1. Create a basic pie chart first: Follow the Pie Chart steps above. Set Marks to Pie, put a dimension on Color, and a measure on Angle.
  2. Duplicate the measure on Rows to create a second identical pie chart:
    • Drag the same measure (e.g., Sales) to Rows again, placing it to the right of the existing pill, OR
    • Hold Ctrl (or Cmd on Mac) and drag the existing measure pill on Rows to duplicate it next to itself.
  3. You now have two identical pie charts side by side. On the second Marks card (select it from the Rows shelf or the card selector), do the following:
    • Remove all pills from Color, Angle, and Label — making it a blank pie.
    • Change its mark type to Circle (not Pie).
    • Drag CNT(1) or MIN(0) to Size to create a small dot, OR simply reduce the Size slider until it becomes a small circle in the center.
    • Set the circle's Color to white (or your background color) to act as the "hole."
  4. Combine into dual axis: Right-click the second measure pill on the Rows shelf (the one for the circle) and select Dual Axis. This overlays the small white circle on top of the pie chart, creating the donut hole.
  5. Adjust the hole size: On the second Marks card (the circle), adjust the Size slider to make the center hole larger or smaller.
  6. Add a label in the center (optional): Drag a measure (e.g., SUM(Sales)) to Label on the circle's Marks card. Format the label to display a summary like total sales in the center of the donut.
  7. Sync axes if needed: Right-click the right axis and select Synchronize Axis to ensure both layers align perfectly.
💡 Alternative Method: Some users create donut charts using a calculated field with value 0 placed on Rows as a "dummy" axis, then use dual axis with a circle mark. Another approach is using floating objects on a dashboard to place a text box over a pie chart — though this is less precise.
💡 Design Tip: The donut's center is perfect for displaying a KPI summary like grand total, average, or YoY change. Use bold, large font for impact.
📈 Line Chart Trend over time

Concept: Shows how a measure changes over a continuous date/time axis. Excellent for identifying trends, seasonality, and anomalies.

Step‑by‑Step Procedure:
  1. Drag a date field to Columns. Ensure it is continuous (green pill). If it's blue (discrete), right-click and select "Convert to Continuous."
  2. Drag a measure (e.g., Sales) to Rows.
  3. On the Marks card, ensure the mark type is set to Line (Tableau usually auto-selects this for date + measure).
  4. Add multiple measures: Drag additional measures to the Rows axis or use Measure Names/Measure Values to overlay multiple lines.
  5. Add forecasting: From the Analytics pane, drag Forecast onto the view. Tableau automatically generates a forecast with prediction bands.
  6. Right-click the date axis to change the granularity (Day, Week, Month, Quarter, Year) or to use exact date vs. discrete date parts.
💡 Pro Tip: Use dual axis to combine a line chart with bars or circles. Drag a second measure to the right side of the Rows axis until you see a dashed line, then release.
Shortcut With one date and one measure, select "Line (continuous)" from Show Me.
🔥 Heat Map Color intensity

Concept: A grid or matrix where color intensity encodes the magnitude of a measure. Great for spotting patterns across two dimensions.

Step‑by‑Step Procedure:
  1. Drag one dimension (e.g., Product Category) to Columns.
  2. Drag another dimension (e.g., Region) to Rows. This creates a cross-tab grid.
  3. Drag a measure (e.g., Profit) to Color on the Marks card. Tableau colors each cell by the measure's value.
  4. On the Marks card, change the mark type dropdown to Square to fill the entire cell with color (instead of circles or text).
  5. Adjust the Size slider to make squares fill the cell space completely.
  6. Optionally, drag the same measure to Label to display the numeric values inside the squares.
  7. Edit the Color legend to choose a sequential or diverging color palette (e.g., Red-Green for profit/loss).
💡 Pro Tip: Combine with Quick Table Calculations (e.g., percent difference, rank) for more advanced heat maps. Use diverging palettes for data with a meaningful midpoint (like zero).
🟩 Treemap Hierarchy & size

Concept: Displays hierarchical data as nested rectangles. The area of each rectangle is proportional to a measure, making it easy to compare parts within a whole, even with many segments.

Step‑by‑Step Procedure:
  1. Drag one or two dimensions to define the hierarchy. The first dimension creates the largest rectangles; the second nests inside them.
  2. Drag a measure (e.g., Sales) to Size on the Marks card. Rectangle area becomes proportional to this measure.
  3. On the Marks card, ensure the mark type is Square. (Tableau auto-selects this when Size is used.)
  4. Drag a dimension to Color to distinguish categories by hue.
  5. Drag dimensions and/or measures to Label to display category names and values inside the rectangles.
  6. Use the Size slider to adjust the visual weight. The treemap algorithm automatically arranges rectangles for optimal space usage.
💡 Pro Tip: Treemaps excel with many categories where bar charts become unwieldy. Use Quick Table Calculation → Percent of Total on the Size measure for proportional comparison.
📋 Highlight Table Text + color

Concept: A text table enhanced with color encoding. Combines the precision of numbers with the visual cues of a heat map. Ideal for detailed reports where exact values matter.

Step‑by‑Step Procedure:
  1. Drag one dimension (e.g., Product) to Rows.
  2. Drag another dimension (e.g., Region) to Columns.
  3. Drag a measure (e.g., Sales) to Text/Label on the Marks card. Tableau displays the number in each cell.
  4. Drag the same measure to Color on the Marks card. The cell background is now color-encoded by value.
  5. Ensure mark type is Square so the color fills each cell entirely.
  6. Format the text (font, size, alignment) by clicking Label on the Marks card.
  7. Edit the Color legend to choose an appropriate palette (sequential for counts, diverging for profit/loss).
💡 Pro Tip: Add Grand Totals (Analysis → Totals) for row/column summaries. Use Borders and Shading formatting to make the table printer-friendly.
🧭 Quick Reference Show Me & tips

Show Me Required Fields:

  • 📊 Bar Chart: 1+ dimension, 1+ measure
  • 📊 Histogram: 1 measure (creates bin auto)
  • 🔵 Scatter Plot: 2 measures (optionally 1 dim)
  • 📦 Box Plot: 1+ dimension, 1 measure
  • 🥧 Pie Chart: 1 dimension, 1 measure
  • 🍩 Donut Chart: Manual (dual-axis from pie chart)
  • 📈 Line Chart: 1 date, 1+ measure
  • 🔥 Heat Map: 1+ dimension, 1 measure
  • 📋 Highlight Table: 1+ dimension, 1 measure
  • 🟩 Treemap: 1+ dimension, 1 measure

General Workflow Tips:

  • 🟢 Green pills = continuous (create axes)
  • 🔵 Blue pills = discrete (create headers)
  • Drag to Detail to disaggregate without coloring
  • Use Analytics pane for reference lines, bands, and distributions
  • Right-click pills for Quick Table Calculations
  • Dual Axis: Right-click second measure on Rows → Dual Axis
  • Donut hole trick: Dual-axis pie + white circle on top
