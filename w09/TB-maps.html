STA 553 Data Visualization

📊 Tableau Maps: Choropleth · Scatter Maps

🎯 Reference cards: concepts and step-by-step workflows
🗺️ Choropleth Map filled polygons
📌 Concept: Geographic areas (states, counties) shaded based on a data measure or ratio. Ideal for rates, densities, or regional comparisons.
🔧 Key Steps (Tableau)
1. Geographic role: set field (State/Country)
2. Double-click geo field → Marks → Filled Map
3. Drag measure to Color (e.g., Profit)
4. Adjust palette & tooltips
📐 Ratio Calculation (best practice)
SUM([Measure]) / SUM([Population]) * 1000 → per capita rate
⚡ tip: avoid raw totals; use normalized values
📍 Scatter / Symbol Map point distribution
📌 Concept: Individual points (stores, events) plotted via lat/long. Point size or color encodes additional measures.
🧭 Build steps
• Latitude → Rows, Longitude → Columns (or double-click)
• Marks: Circle / Shape
• Size → measure (e.g., Sales), Color → measure or category
✍️ Custom Lat/Long field
If Address exists, combine: [Address]+", "+[City]+", "+[State]
Set geographic role to "Address"
💡 use dual axis with density layer for hot spots
🧮 Choropleth: Formulas & Agg rate calculation
✅ Rate / Density formula (calculated field)
SUM([Number of cases]) / SUM([Total population]) * 10000
→ per 10,000 residents (adjust multiplier)
📦 Tableau specific: Fixed Level of Detail
{ FIXED [State] : AVG([Population Density]) }
🎨 diverging color palettes for positive/negative change
🔍 Advanced Scatter Map clusters & filters
⚡ Clustering marks: On Marks card → dropdown → Cluster. Tableau groups proximate points.
🔄 Dual Axis: Symbol + Density Heatmap
1. Duplicate longitude field (Ctrl+drag)
2. Dual Axis → synchronize axes
3. Change 2nd mark to Density (Hexbin)
📍 Custom geocoding with Latitude/Longitude fields:
If your dataset includes lat/lon numbers, drop them directly onto Rows/Columns, remove aggregation if needed.
🎯 Use Map Layers to turn off labels for clean point focus
🗺️ Map Layers & Styling cartography
🌍 Background maps: Map → Background Maps → Normal / Dark / Streets / Off (for simple polygons).
🛠️ Map Layers panel:
- Show map scale, zone & country borders
- Data Layer: demographic overlays (US only)
- Washout background: 0% to 100%
💎 Custom WMS / Mapbox: Map → Background Maps → Map Services → Add.
📌 tip: duplicate map layers for label-only layer
🚀 Performance & Fixes extract & indexing
⚙️ Speed up large datasets: Use Data Extract instead of live connection; apply spatial indexes.
🛡️ Missing geographic locations: Right-click geographic field → Edit Locations → match to Tableau's geocoding hierarchy.
📌 Choropleth not showing? Ensure field has assigned geographic role and is a filled map type. For scatter map, verify lat/lon fields are numeric decimals.
🔧 quick fix: change geographic role → reset if unrecog.
